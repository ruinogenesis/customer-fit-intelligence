# Tuning the paper

The built PDF is no longer committed: `main.tex` is the paper, and you build
it to read it (`README.md` says how). This file records each round of tuning:
what changed, where it stands, and whether the limits below still hold.

## Limits every round keeps

- [ ] 8 pages in the IEEE conference layout
- [ ] An abstract of 250 words or fewer
- [ ] 21 references, numbered in the order they are first cited
- [ ] No overfull or underfull lines, no undefined references, no Type 3 fonts
- [ ] No number changed unless its result file changed (`SOURCES.md` names
      the file); `SUPPLEMENT.md` updated with any number that moved
- [ ] The title and byline as they are

Copy this list into a round when you check it.
